# PRODUCT.md

## Product Name (Working)

WhatsApp Dev  
(working description: “Your developer on WhatsApp or Telegram”)

---

## One-Line Description

A WhatsApp or Telegram handle that builds, deploys, and edits business websites through chat — powered by autonomous coding agents.

---

## Problem

Small and medium businesses (SMBs) need websites, but:

- Agencies are slow, expensive, and high-friction
- DIY builders require time, decisions, and learning
- Even small edits feel annoying or delayed
- SMB owners already operate their business through WhatsApp or Telegram

They don’t want tools.  
They want outcomes.

---

## Target Users

### Primary

- SMB owners (barbers, salons, gyms, restaurants, clinics, local services)
- Non-technical operators
- Founders who prefer chat-based workflows

### Secondary (later)

- Solo founders
- Indie hackers
- Agencies managing multiple client sites

---

## Core Value Proposition

**Describe what you want in WhatsApp or Telegram → get a live website → edit it by texting.**

Users never:

- open an editor
- choose templates
- manage hosting
- touch code

---

## Core Use Cases

### 1. New Website Creation (Dynamic)

User messages:

> “I need a modern website for a barber shop in Athens, black and gold, premium vibe.”

The system:

- Asks minimal clarifying questions (if needed)
- Dynamically designs layout + sections
- Writes copy tailored to the business
- Pulls relevant images from Unsplash
- Deploys a live site
- Returns the link via WhatsApp or Telegram

There are **no predefined templates**.  
Layouts are assembled dynamically based on intent, business type, and brand cues.

---

### 2. Website Edits via Chat

User messages:

- “Make it more luxury”
- “Change price from 20 to 25”
- “Add booking button”
- “Add English version”
- “Move gallery higher”
- “Replace photos with these” (uploads images)

The system:

- Applies targeted changes
- Redeploys the site
- Replies with confirmation + updated link

---

### 3. Image Sourcing (Unsplash)

Instead of generating images:

- The system searches Unsplash using business + section context
- Selects high-quality, license-safe images
- Automatically crops/resizes for web
- Replaces placeholders seamlessly

User can later override by uploading their own photos.

---

## MVP Feature Set (In Scope)

### Messaging Interface

- WhatsApp and Telegram as chat interfaces (Telegram first for MVP)
- Text messages + image uploads
- Short, guided responses (no long explanations)

---

### Website Capabilities

- One-page or simple multi-page sites
- Dynamically generated layouts (no templates)
- Common sections (generated as needed):
  - Hero
  - Services
  - Pricing
  - Gallery
  - Testimonials
  - Location / Map
  - Contact / WhatsApp or Telegram CTA
- Mobile-first
- SEO-friendly structure by default

---

### Deployment

- Automatic deployment to a live URL
- Hosted on platform-managed domains
- Redeployed on every edit

---

### Memory & Continuity

The system remembers:

- Business name & location
- Brand tone (luxury, minimal, playful, etc.)
- Color preferences
- Language choices
- Previous edits and decisions

This memory persists across conversations.

---

## Out of Scope (for MVP)

- Predefined templates
- Image generation (AI art)
- User dashboards or editors
- Payments / subscriptions
- Analytics dashboards
- Domain purchasing
- Advanced SEO tooling
- Ads / marketing automation

---

## Product Principles

### 1. Chat Is the Interface

WhatsApp and Telegram are the product.
Everything else is invisible.
Telegram is the initial launch surface to move fast; WhatsApp follows once approved.

---

### 2. No Templates, No Choices

Users never pick layouts or themes.
The system decides unless told otherwise.

---

### 3. Fast First Result

The first live site should appear within minutes.

---

### 4. Editability Is the Core Loop

Retention comes from frictionless edits via chat.

---

### 5. Opinionated by Default

Good defaults > endless options.

---

## Differentiation

Unlike:

- Website builders → no UI, no setup
- Agencies → instant turnaround
- Freelancers → always available
- AI site generators → persistent, editable, conversational

This product behaves like:
**A personal developer reachable through WhatsApp or Telegram.**

---

## Success Metrics (Early)

- Time to first live site
- % of users requesting edits
- Average edits per user
- Repeat usage after first deploy
- Qualitative “wow” reactions

---

## Long-Term Vision (Not MVP)

- Subscription plans with edit limits
- Multi-site support per user
- Custom domains
- Agency / reseller mode
- Other chat surfaces (SMS)
- Human-assisted premium tier

---

## Non-Goals

- Replacing full-service agencies
- Supporting complex web apps
- Exposing technical controls to users

---

## Product Summary

This product turns **natural language into deployed software**.

If a user can explain it in WhatsApp or Telegram,  
the system should be able to build or change it.
